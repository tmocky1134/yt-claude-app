Privacy policy

Last updated: 25 November 2026

This policy covers youtube-claude, a private tool used only by its owner to work with their own YouTube channel through the YouTube Data API v3.

Data accessed

With the owner's consent (scope https://www.googleapis.com/auth/youtube.force-ssl), the app can access the owner's YouTube data: channel information, videos, playlists and comments. It does not access data of any other Google account.

How data is used

Data is used only to carry out tasks the owner requests, such as listing videos or updating playlists. It is not sold, not used for advertising, and not shared with anyone other than the services needed to perform the request (Google's YouTube API and the AI assistant the owner uses, Claude Code by Anthropic).

Storage

The app stores no YouTube data of its own. The OAuth credentials are kept in the owner's private Claude Code cloud environment and are used only to call the YouTube Data API on the owner's behalf.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
